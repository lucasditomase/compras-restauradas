## Importante

- Esta tabla solo se aplica a las descargas de aplicaciones de pago. Las compras realizadas dentro de la aplicación, como suscripciones y compras únicas, siempre se restauran automáticamente, independientemente de la versión de la aplicación.
- Si está utilizando una versión anterior a la de la tabla, es posible que la restauración de la compra no funcione.
- Algunas aplicaciones no pueden restaurar el 100% de las compras debido a las limitaciones actuales de las API utilizadas. Una vez que se resuelvan las limitaciones, esas compras se restaurarán, y esta tabla se actualizará para reflejar eso.
